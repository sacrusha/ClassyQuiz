A question on screen

How the classyQuiz projector lays out a question, and how a student's device shows its answers: the markup, and the rules from the site's stylesheet. Two things the stylesheet doesn't carry are in comments: the type sizes, which a script sets from the length of the text, and what the reveal adds.

Markup

<!-- The projector, one question. Always the light theme: projectors wash out dark backgrounds. -->
<body class="screen"><main>
  <div class="bar"><span>2 / 12</span><span class="grow"></span><span>👤 <span>17 / 24</span></span></div>
  <h2 class="qtext">A jacket costs 80 francs and is reduced by 25%. What does it cost now?</h2>
  <div class="tiles">
    <div class="tile a0"><svg class="shape" viewBox="0 0 100 100"><path d="M50 12 L90 84 H10Z"/></svg><span class="txt">55 francs</span><span class="side"></span></div>
    <div class="tile a1"><svg class="shape" viewBox="0 0 100 100"><path d="M50 8 L92 50 L50 92 L8 50Z"/></svg><span class="txt">20 francs</span><span class="side"></span></div>
    <div class="tile a2"><svg class="shape" viewBox="0 0 100 100"><circle cx="50" cy="50" r="40"/></svg><span class="txt">75 francs</span><span class="side"></span></div>
    <div class="tile a3"><svg class="shape" viewBox="0 0 100 100"><rect x="13" y="13" width="74" height="74" rx="4"/></svg><span class="txt">60 francs</span><span class="side"></span></div>
  </div>
</main></body>
<!-- At the reveal: a tile that doesn't count gets the class "dim"; every tile's .side becomes
     <span class="mark">✓</span> (only on a tile that counts) <span class="n">17</span> (how many picked it),
     and each tile gets <span class="fill" style="width: 100 × its count ÷ the highest count %"></span>. -->

<!-- A student's phone or tablet: the answers as buttons, the question is on the projector. -->
<body class="play"><main>
  <div class="buttons n4">
    <button class="ansbtn a0"><svg class="shape" viewBox="0 0 100 100"><path d="M50 12 L90 84 H10Z"/></svg><span>55 francs</span></button>
    <button class="ansbtn a1"><svg class="shape" viewBox="0 0 100 100"><path d="M50 8 L92 50 L50 92 L8 50Z"/></svg><span>20 francs</span></button>

Stylesheet

:root { --bg: #fbf8f2; --fg: #1d1d1b; --muted: #5d5c57; --good: #1f8a4c; --bad: #c62828; }
body { margin: 0; background: var(--bg); color: var(--fg); font: 17px/1.45 system-ui, -apple-system, "Segoe UI", Roboto, sans-serif; }
.a0 { --ans: #d93b3b; --ans-ink: #fff; }      /* 1st answer: red triangle   */
.a1 { --ans: #2f6fd6; --ans-ink: #fff; }      /* 2nd: blue diamond          */
.a2 { --ans: #e8b100; --ans-ink: #1b1b1f; }   /* 3rd: yellow circle         */
.a3 { --ans: #1f9d55; --ans-ink: #fff; }      /* 4th: green square          */
.shape { width: 1em; height: 1em; display: inline-block; flex: none; fill: currentColor; }

/* Projector */
body.screen { overflow: hidden; height: 100dvh; font-size: clamp(16px, 1.6vw, 40px); }
.screen main { height: 100dvh; display: flex; flex-direction: column; padding: 2.2vh 2.5vw; gap: 2vh; }
.screen .bar { display: flex; align-items: center; gap: 1.2em; font-weight: 700; color: var(--muted); font-size: 1.2em; }
.screen .bar .grow { flex: 1; }
.qtext { font-weight: 700; text-align: center; line-height: 1.2; margin: 0; overflow-wrap: anywhere; display: flex; align-items: center; justify-content: center; flex: 0 1 auto; min-height: 18vh; }
/* .qtext font-size is set by script from the question's length: up to 40 characters 3.6em, up to 90 3em,
   up to 160 2.4em, longer 1.9em; then reduced in 0.15em steps until the question fits in 34vh, down to 1.1em. */
.tiles { flex: 1; display: grid; grid-template-columns: 1fr 1fr; gap: 1.6vh; min-height: 0; }
/* .tiles font-size is set by script from the longest answer: up to 12 characters 2.6em, up to 30 2em,
   up to 60 1.55em, longer 1.25em; then reduced in 0.1em steps until no tile overflows, down to 1em;
   if it still overflows, words are broken. */
.tile { background: var(--ans); color: var(--ans-ink); border-radius: 18px; display: flex; align-items: center; gap: .6em; padding: 1.2vh 1.6vw; font-weight: 700; position: relative; overflow: hidden; min-height: 0; }
.tile .shape { width: 1.6em; height: 1.6em; }
.tile .txt { flex: 1; min-width: 0; line-height: 1.15; }
.tile .side { flex: none; width: 3.4em; display: flex; align-items: center; justify-content: flex-end; gap: .2em; }
.tile .n { font-size: 1.3em; font-weight: 800; font-variant-numeric: tabular-nums; }
.tile .fill { position: absolute; left: 0; bottom: 0; height: 1.6vh; background: currentColor; opacity: .7; }
.tile.dim { opacity: .5; }

.play .buttons.n2 { grid-template-columns: 1fr; }

.ansbtn .shape { width: clamp(52px, 12vmin, 140px); height: clamp(52px, 12vmin, 140px); }
